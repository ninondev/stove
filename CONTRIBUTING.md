# Contributing

Pull requests are welcome. The maintainer reads issues.

Use Python 3.12 or later. Run the demos from the repository folder. Before sending a change, run:

```sh
nice -n 10 python3 -m pytest
```

Tests need pytest. Please add a test for behavior that your change affects. Use made-up data in tests and examples. Do not add real restaurant data or printer addresses.

Read [CLA.md](CLA.md). The comment `I have read the CLA and I agree to it.` is required on your pull request before merge.
